# 퇴근길 감 테스트 💗

퇴근길 숫자, 당신의 감은 몇 점? — 공식 통계와 공개 데이터로 만든 숫자 맞히기 퀴즈입니다.

주소: https://github.com/monomono0809/gam-test

## 내 주제

💼 **일하는 우리, 얼마나 만족할까** — 2025년 조사로 본 일터의 숫자 (AI 활용 · 만족도 · 근속)

출처: 국가데이터처 2025년 사회조사 · 한국은행 · e-나라지표

## 내가 내린 판단

질문은 누구나 쉽게 이해할 수 있도록 만들고, 조사 대상과 기준연도를 명확히 표시했다. 정답은 반올림된 세부 수치를 다시 계산하지 않고 공식 통계표에 발표된 값을 사용했다.

## 돌려보기

```
python -m http.server 8000      # index.html 을 더블클릭하면 안 됩니다
```

## 데이터가 오는 길

```
   [내 노트북]                                   [인터넷]

   tools/fetch_all.py      공개 데이터 6곳에서 받기 (키·로그인 없음)
        ↓  data/raw/  약 19MB   ← git 에도 배포에도 올라가지 않습니다
   tools/build_topics.py   원본에서 문항 계산
        ↓
   topics/*.json  약 40KB  ← 이것만 올라갑니다
```

원본을 브라우저로 보내서 거기서 평균을 내는 게 아닙니다. **평균은 내 노트북에서 미리
내고, 그 결과만 싣습니다.** 그래서 폰에서 즉시 뜹니다.
